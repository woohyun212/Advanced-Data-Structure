> 환경: **(Linux/Mac/Windows) + gcc + Makefile**

## 🧩 필수 복구 (40점)

- [ ] **make()** [우현]
    - [ ] 삭제된 **호출 및 루프 구조** 복구  
      → 그림 그리기 루프가 정상 동작하도록 누락된 호출부 추가
- [x] **filewrite1()** [준서]
    - [ ] 삭제된 **파일 출력 루프** 복구  
      → `picture` 배열을 순회하며 `putc` 또는 `fprintf`로 파일에 기록
- [x] **filewrite2()** [준서]
    - [ ] 삭제된 **출력 루프 및 파일 포인터 처리** 복구  
      → `FILE *fp`를 사용하여 파일을 정상적으로 닫고 기록
- [ ] **mon()** [아정]
    - [ ] 삭제된 **격자(grid) 출력 루프** 복구  
      → `longx`, `longy` 기준으로 `','` 문자를 사용해 격자를 재출력

## 🎨 필수 보완 (40점)

- [ ] **textcolor(int color)**
    - [ ] ANSI 이스케이프 코드(`\033[3xm`)를 사용해 색상 변경
        - 예시 색상 코드: `10`, `9`, `11`, `15`
    - [ ] 출력 후 **리셋 코드(`\033[0m`)**로 복원
- [ ] **make() 확장**
    - [ ] `'r'` 키 입력 시 그림판 초기화 기능 추가  
      → `picture` 배열 전체를 `' '` (공백)으로 초기화  
      → 화면도 즉시 재출력하여 초기 상태로 갱신
